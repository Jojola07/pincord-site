## 📌 Sobre

Este repositório contém o **site de apresentação** do PinCord — a página que apresenta o bot, seus comandos, features e oferece o link de convite direto pro Discord.

O site é **100% estático** (HTML, CSS e JavaScript puros), sem frameworks, sem build, sem dependências. Isso significa que ele carrega rápido e pode ser hospedado em qualquer serviço gratuito (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

> 🤖 **Procurando o código do bot?** O repositório do bot é privado no momento.

## ✨ Funcionalidades da página

- 🎨 **Design moderno** com tema roxo e vermelho, combinando com a identidade do bot
- 🌙 **Tema escuro nativo** com efeitos de brilho e gradientes
- 📱 **Totalmente responsivo** — funciona em celular, tablet e desktop
- ⚡ **Leve e rápido** — sem dependências além da fonte Inter
- 🎭 **Animações suaves** ao rolar, no logo e nos botões
- 🔗 **Botão de copiar link de convite** com feedback visual (toast)
- 📖 **FAQ interativo** com accordion
- 🖼️ **Preview do bot no Discord** com mockup realista
- 📋 **Seção de comandos** com ícones SVG de cada funcionalidade
- 🌐 **SEO e Open Graph** — link fica bonito ao compartilhar em redes sociais
