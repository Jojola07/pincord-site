Comandos

Tudo o que você pode fazer

Slash commands simples, com autocomplete nativo do Discord.

/pin
Salva uma imagem numa pasta com título, descrição e tags.
/inicio
Menu principal com atalhos para Populares, Recentes, Antigos, Pastas e Meus pins.
/pasta criar
Cria uma nova pasta, com nome e emoji personalizados.
/pasta listar
Lista todas as pastas do servidor com contagem de pins.
/pasta ver
Abre uma pasta e navega pin por pin com os botões ◀ ▶.
/search
Busca pins por título, descrição ou tags em todo o servidor.
/random
Mostra um pin aleatório do servidor — bom pra descobrir coisa nova.
/mypins
Mostra todos os pins que você já salvou (só você vê).
/unpin
Remove um pin seu pelo ID.
/ajuda
Mostra todos os comandos disponíveis com explicações.
Salvar (botão)
Salva pins de outras pessoas direto numa pasta sua. Incrementa o ranking de populares.
